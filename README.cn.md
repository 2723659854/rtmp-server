### 架构说明
- **源站服务**：唯一流生产节点，负责 RTMP 推拉流接入、多协议转封装、本地录制存储。
- **FLV 网关**：纯流量转发服务，向上拉取 HTTP-FLV 流、缓存 GOP 关键帧实现播放秒开，向下分发至终端客户端或下级网关。
- **Nginx**：项目自带简易 HTTP 服务可直接播放 HLS/FLV/MP4；生产环境推荐 Nginx 托管静态分片文件，分担静态资源访问压力。
- **部署建议**：源站专注「推流、转码、录制」，网关承接「用户拉流播放」。低并发场景可单源站裸跑；高并发按需多级网关横向扩容。

## ✨ 功能特性
- 🎥 **完整 RTMP 推拉流**：全协议实现，支持标准 publish / play 指令
- 📡 **HTTP-FLV / WebSocket-FLV**：浏览器低延迟直播方案
- 🧩 **HLS 自动分片**：实时生成 m3u8 + TS，全平台移动端兼容
- 💾 **全自动录制**：推流时可选开启录制，自动生成 FLV 原片、混合fMP4、分离音视频fMP4、合并MP4
- 🖥️ **内置多套Web播放器**：开箱即用，无需额外前端开发
- 🚀 **可级联FLV流媒体网关**：无限层级分流、GOP缓存秒开、断流自动重连
- 🐳 **Docker 一键部署**：快速拉起测试环境
- ⚡ **原生纯PHP实现**：不绑定 Nginx、SRS、LiveGO 等第三方流媒体程序

## 🚀 FLV 流媒体网关
### 网关简介
轻量化流量分发组件，支持无限层级级联部署。从上游源站/上级网关拉取 HTTP-FLV，缓存流头与 GOP 关键帧，新用户接入秒开，并复制流数据下发客户端或子网关。

### 网关核心能力
- 📡 单实例多路流并发转发，同时承载不同频道直播分发
- 🔄 无限层级级联，一级→二级→三级网关链式扩展
- ⚡ GOP预缓存，新连接无需等待关键帧，实现秒开播放
- 🔁 上游流断开自动重连，终端用户无感知断线
- 📊 内置运行统计，每10秒输出在线人数、上下行流量

### 网关启动命令
```bash
# 一级网关：拉取源站流
php gateway.php 8080 http://源站IP:8501

# 二级网关：拉取一级网关流
php gateway.php 8080 http://一级网关IP:8080

# 三级网关：拉取二级网关流
php gateway.php 8080 http://二级网关IP:8080
```

### 网关播放地址规范
```
http://网关IP:8080/{应用名}/{频道名}.flv
```

```
# 一级网关
```

## 📡 推流接入教程
### RTMP推流地址格式
```
rtmp://127.0.0.1:1935/{应用名}/{频道名}
```
- `应用名`：示例 `live`
- `频道名`：示例 `stream`
- 仅支持英文、数字命名

### 推流示例
#### OBS Studio 推流
1. 下载安装 [OBS Studio](https://obsproject.com/)
2. 设置 → 推流 → 服务器：`rtmp://127.0.0.1:1935/live`
3. 串流密钥：`stream`
4. 开始推流

#### FFmpeg 循环推流
```bash
ffmpeg -re -stream_loop -1 -i "video.mp4" \
  -vcodec h264 -acodec aac -f flv \
  rtmp://127.0.0.1:1935/live/stream
```

## 💾 自动录制说明
### 录制流程
1. **推流开始** → 实时录制原生FLV码流
2. **推流结束** → 保存FLV源文件，自动转码生成多规格MP4/fMP4资源

### 文件存储目录
| 文件类型           | 存储路径                                              | 备注 |
| ------------------ | ----------------------------------------------------- | ---- |
| 原始FLV文件        | `./flv/{应用名}/{频道名}/`                            | 实时录制裸流 |
| 混合音视频fMP4     | `./mp4/{应用名}/{频道名}/output_merge/`               | 音视频同片，浏览器MSE直播 |
| 分离音视频fMP4     | `./mp4/{应用名}/{频道名}/output_separate/`            | 音频、视频分片隔离 |
| 完整合并MP4        | `./mp4/{应用名}/{频道名}/output_merge/{频道名}_full.mp4` | 全片拼接成品 |

> 混合分片：单分片同时包含音视频，适配HTML5 Video + MSE；
> 分离分片：音视频文件拆分，用于自定义精细化播放场景。

### 录制注意事项
- ✅ 原始FLV可用VLC、PotPlayer直接打开播放
- ✅ 混合fMP4、全量MP4为标准格式，支持拖拽播放、进度跳转
- ✅ 分离分片通过`play_merge.html`借助浏览器MSE解码播放
- ⚠️ **同应用+同频道重复推流会覆盖旧录制文件**
- ⚠️ 服务不会自动清理过期文件，业务需自行做定时清理脚本

### 离线手动转码（可选）
修改`server.php`内开关控制自动录制；项目依赖 `xiaosongshu/flv2mp4` 组件，支持离线文件互转：
```php
<?php
require_once __DIR__ . '/vendor/autoload.php';
ini_set('memory_limit', '512M');
$file = __DIR__."/test.flv";

// 示例1：FLV → 混合fMP4 + 完整MP4
$outputDir1 = __DIR__."/output_merge";
try{
    $res = \Xiaosongshu\Flv2mp4\Client::runFlv2mp4($file, $outputDir1);
    echo "转换完成: " . $res;
}catch (\Exception $e){
    echo "错误: " . $e->getMessage();
}

// 示例2：FLV → 音视频分离fMP4
$outputDir2 = __DIR__."/output_separate";
try{
    $res = \Xiaosongshu\Flv2mp4\Client::runFlv2mp4Separate($file, $outputDir2);
}catch (\Exception $e){}

// 示例3：FLV ↔ HLS、MP4 ↔ FLV 互转详见源码注释
```
> `xiaosongshu/flv2mp4` 为本项目拆分独立组件，支持 FLV/MP4/HLS 全格式互转，项目直播实时转码内部已集成。

## ❓ 常见问题 FAQ
### 1. 启动提示缺少扩展
- 原因：PHP-CLI 与 FPM 使用两套不同 `php.ini`
- 处理：`php -m` 查看已装扩展，补充`sockets`；推荐Docker环境规避环境问题。

### 2. 端口占用无法启动
- 排查：Windows `netstat -ano | findstr 端口` / Linux `lsof -i:端口`
- 处理：修改`server.php`端口配置，同步修改前端页面内置地址。

### 3. 网页播放器无法拉流
1. 确认服务正常运行、防火墙放行端口
2. 核对页面内播放地址和推流 `app/stream` 名称一致
3. 自定义端口后同步修改HTML内写死地址

### 4. 再次推流覆盖历史录制
- 方案：每次开播使用唯一频道名；自行开发定时归档脚本。

### 5. 推流结束无录制文件
项目默认配置：**仅开启HLS转码，FLV录制、MP4转码默认关闭**
修改`server.php`三个常量：
- `FLV_TO_HLS`：HLS实时切片开关
- `FLV_TO_MP4`：fMP4/MP4录制开关
- `FLV_TO_RECORD`：原生FLV录制开关

### 6. 网关播放卡顿、频繁掉线
1. 检查上游源站网络稳定性
2. 建议网关层级≤3级，层级越多延迟越高
3. 开启网关Debug日志定位异常：`$gateway->debug = true;`
