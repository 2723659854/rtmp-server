### 架构说明

- **源站服务**：唯一流生产节点，负责 RTMP 推拉流接入、多协议转封装。**FLV录制、fMP4切片、HLS切片三个任务完全独立并行运行**，互不阻塞。

- **源站静态能力**：源站内置 HTTP 服务（默认80端口），可直接提供静态文件访问。**低并发场景下无需额外部署网关**，开箱即用。

- **实时录制机制**：
    - **FLV录制**：实时保存原始裸流，直播结束后得到完整FLV文件
    - **fMP4切片**：实时生成音视频 fMP4 分片（支持混合切片和分离切片两种格式），直播结束后自动合并为完整 MP4
    - **HLS切片**：实时生成 TS 分片 + m3u8 索引（移动端兼容）
    - **独立开关**：用户可在 `server.php` 中分别配置是否开启各录制任务

- **FLV 直播网关**：纯流量转发服务，向上拉取 HTTP-FLV 流、缓存 GOP 关键帧实现播放秒开，向下分发至终端客户端或下级网关。**专为高并发直播场景设计**，支持无限层级级联扩容。

- **静态文件网关**：轻量级 HTTP 静态文件服务器，统一托管所有静态资源。**专为高并发点播场景设计**，承载百万级静态资源访问。托管内容包括：
    - HLS TS切片 + m3u8索引
    - fMP4分片文件（混合切片/分离切片）
    - 合并后的完整 MP4 点播文件
    - FLV 录制文件
    - Web 播放页面（`index.html`、`play.html`、`mp4.html`、`play_merge.html` 等）

- **部署建议**：
    - **低并发场景**（< 1000 并发）：直接使用源站内置 HTTP 服务，无需额外网关
    - **高并发场景**（> 1000 并发）：
        - 源站专注「推流、协议转换、实时录制」
        - FLV 网关集群承载「直播拉流播放」，横向扩容应对百万级直播并发
        - 静态文件网关集群承载「点播回放资源 + 播放页面」，横向扩容应对百万级点播并发

## ✨ 功能特性

- 🎥 **完整 RTMP 推拉流**：全协议实现，支持标准 publish / play 指令
- 📡 **HTTP-FLV / WebSocket-FLV**：浏览器低延迟直播方案
- 🧩 **HLS 自动分片**：实时生成 m3u8 + TS，全平台移动端兼容
- 📦 **fMP4 实时切片 + 自动合并**：直播时实时生成 fMP4 分片，直播结束自动合并为完整 MP4
- 🎬 **双 fMP4 格式支持**：同时支持音视频混合切片和音视频分离切片两种格式
- 💾 **FLV 独立录制**：实时保存原始 FLV 裸流，与 fMP4/MP4 解耦
- 🎛️ **独立任务开关**：FLV录制、fMP4切片、HLS切片可分别独立配置启用/禁用
- 🖥️ **内置多套Web播放器**：开箱即用，支持 FLV/HLS/MP4/混合fMP4/分离fMP4 播放
- 🚀 **可级联FLV流媒体网关**：无限层级分流、GOP缓存秒开、断流自动重连，支撑百万级直播并发
- 📁 **静态文件网关**：统一托管录制资源 + 播放页面，支撑百万级点播并发
- 🐳 **Docker 一键部署**：快速拉起测试环境
- ⚡ **原生纯PHP实现**：不依赖任何第三方流媒体程序

## 🚀 快速开始

### 1. 安装项目
```bash
composer create-project xiaosongshu/rtmp_server
```

### 2. 配置录制开关（`server.php`）
```php
// 三个独立录制任务开关，可根据需要分别开启/关闭
define('FLV_TO_RECORD', true);   // 是否实时录制FLV原始文件
define('FLV_TO_MP4', true);      // 是否实时生成fMP4切片并合并为MP4
define('FLV_TO_HLS', true);      // 是否实时生成HLS(TS)切片
```

### 3. 启动源站服务
```bash
php server.php
```

### 4. 访问播放（低并发场景直接使用源站）
```bash
# 播放页面访问（源站内置HTTP服务）
http://127.0.0.1/index.html      # FLV直播页面
http://127.0.0.1/play.html       # HLS直播页面
http://127.0.0.1/mp4.html        # MP4点播页面
http://127.0.0.1/play_merge.html # fMP4分片点播页面（支持混合/分离两种格式）
```

### 5. 高并发场景：启动静态文件网关
```bash
# 默认端口 8100，托管当前目录下所有静态文件
php fileGateway.php 0.0.0.0 8100
```

### 6. 高并发场景：启动 FLV 直播网关
```bash
# 一级网关：拉取源站流
php flvGateway.php 8080 http://源站IP:8501
```

### 7. 停止服务
| 操作系统    | 终止命令       |
| ----------- | -------------- |
| Windows     | `Ctrl + C`     |
| Linux/macOS | `kill -9 PID`  |

## 🚀 FLV 流媒体网关（高并发直播分发）

### 网关简介

轻量化流量分发组件，支持无限层级级联部署。从上游源站/上级网关拉取 HTTP-FLV，缓存流头与 GOP 关键帧，新用户接入秒开，并复制流数据下发客户端或子网关。**专为高并发直播场景设计**，可横向扩容支撑百万级直播并发。

### 网关核心能力

- 📡 单实例多路流并发转发，同时承载不同频道直播分发
- 🔄 无限层级级联，一级→二级→三级网关链式扩展
- ⚡ GOP预缓存，新连接无需等待关键帧，实现秒开播放
- 🔁 上游流断开自动重连，终端用户无感知断线
- 📊 内置运行统计，每10秒输出在线人数、上下行流量
- 🚀 横向扩容：增加网关节点即可线性提升并发能力

### FLV网关启动命令

```bash
# 一级网关：拉取源站流
php flvGateway.php 8080 http://源站IP:8501

# 二级网关：拉取一级网关流
php flvGateway.php 8080 http://一级网关IP:8080

# 三级网关：拉取二级网关流
php flvGateway.php 8080 http://二级网关IP:8080
```

### 网关播放地址规范

```
http://网关IP:8080/{应用名}/{频道名}.flv
```

示例：
```
# 一级网关
http://127.0.0.1:8080/live/stream.flv
# 二级网关
http://127.0.0.1:8081/live/stream.flv
```

### 调试日志

网关启动脚本添加 `$gateway->debug = true;`，开启全量详细运行日志。

## 📡 推流接入教程

### RTMP推流地址格式

```
rtmp://127.0.0.1:1935/{应用名}/{频道名}
```

- `应用名`：示例 `live`
- `频道名`：示例 `stream`
- 仅支持英文、数字命名

### 推流示例

#### OBS Studio 推流
1. 下载安装 [OBS Studio](https://obsproject.com/)
2. 设置 → 推流 → 服务器：`rtmp://127.0.0.1:1935/live`
3. 串流密钥：`stream`
4. 开始推流

#### FFmpeg 循环推流
```bash
ffmpeg -re -stream_loop -1 -i "video.mp4" \
  -vcodec h264 -acodec aac -f flv \
  rtmp://127.0.0.1:1935/live/stream
```

## 💾 实时录制说明

### 录制机制（三任务独立并行）

推流开始后，源站同时启动三个**独立并行**的录制任务，互不阻塞：

```
                    ┌─────────────────────────────────────────────────┐
                    │                  RTMP 推流                       │
                    └─────────────────────┬───────────────────────────┘
                                          │
                    ┌─────────────────────┼───────────────────────────┐
                    │                     │                           │
                    ▼                     ▼                           ▼
            ┌───────────────┐     ┌───────────────┐           ┌───────────────┐
            │   FLV录制     │     │   fMP4切片    │           │   HLS切片     │
            │  (实时裸流)   │     │  (实时分片)   │           │  (实时分片)   │
            └───────┬───────┘     └───────┬───────┘           └───────┬───────┘
                    │                     │                           │
                    ▼                     ▼                           ▼
            ┌───────────────┐     ┌───────────────┐           ┌───────────────┐
            │  完整FLV文件  │     │  fMP4分片集   │           │   TS分片集    │
            │  (直播结束)   │     │  (直播中)     │           │  + m3u8索引   │
            └───────────────┘     └───────┬───────┘           └───────────────┘
                                          │
                                          │ 直播结束后自动合并
                                          ▼
                                    ┌───────────────┐
                                    │  完整MP4文件  │
                                    │  (点播回放)   │
                                    └───────────────┘
```

### 任务独立性说明

| 录制任务     | 实时性     | 产出物                     | 用途                       | 独立开关              |
| ------------ | ---------- | -------------------------- | -------------------------- | --------------------- |
| **FLV录制**  | 实时       | 完整FLV文件                | 原始格式备份、VLC播放      | `FLV_TO_RECORD`       |
| **fMP4切片** | 实时       | fMP4分片 → 结束后合并为MP4 | 浏览器MSE播放、点播回放    | `FLV_TO_MP4`          |
| **HLS切片**  | 实时       | TS分片 + m3u8              | 移动端兼容、HLS直播        | `FLV_TO_HLS`          |

> 三个任务彼此独立，互不影响。例如可以只开启 HLS 切片而不录制 FLV，也可以只录制 FLV 而不生成 fMP4。

### fMP4 双格式支持

| 格式类型         | 存储路径                        | 特点                               | 适用场景                 |
| ---------------- | ------------------------------- | ---------------------------------- | ------------------------ |
| **混合切片**     | `output_merge/`                 | 音视频在同一分片，单SourceBuffer    | 简单实现，兼容性较好     |
| **分离切片**     | `output_separate/`              | 音视频分片独立，双SourceBuffer同步  | 精细化控制，音视频独立处理 |

> `play_merge.html` 播放页面同时支持以上两种格式，自动识别并选择对应的播放策略。

### 文件存储目录

| 文件类型           | 存储路径                                              | 备注                           |
| ------------------ | ----------------------------------------------------- | ------------------------------ |
| 原始FLV文件        | `./flv/{应用名}/{频道名}/`                            | 实时录制裸流                   |
| 混合音视频fMP4     | `./mp4/{应用名}/{频道名}/output_merge/`               | 实时分片，结束后合并为MP4      |
| 分离音视频fMP4     | `./mp4/{应用名}/{频道名}/output_separate/`            | 音频、视频分片隔离             |
| 完整合并MP4        | `./mp4/{应用名}/{频道名}/output_merge/{频道名}_full.mp4` | **直播结束后自动合并生成**   |
| HLS TS切片         | `./hls/{应用名}/{频道名}/`                            | 实时分片，供HLS直播           |

> 所有录制文件均可通过源站内置HTTP服务或静态文件网关访问。

### 录制注意事项

- ✅ **任务独立**：三个录制任务可分别开启/关闭，互不干扰
- ✅ **实时切片**：fMP4和HLS在推流过程中实时生成分片，支持中途播放
- ✅ **自动合并**：直播结束后，fMP4分片自动合并为完整MP4文件
- ✅ **双格式支持**：fMP4同时支持混合切片和分离切片两种格式
- ✅ 混合fMP4、全量MP4为标准格式，支持拖拽播放、进度跳转
- ⚠️ **同应用+同频道重复推流会覆盖旧录制文件**
- ⚠️ 服务不会自动清理过期文件，业务需自行做定时清理脚本

## ❓ 常见问题 FAQ

### 1. 启动提示缺少扩展

- **原因**：PHP-CLI 与 FPM 使用两套不同 `php.ini`
- **处理**：`php -m` 查看已装扩展，补充`sockets`；推荐Docker环境规避环境问题。

### 2. 端口占用无法启动

- **排查**：Windows `netstat -ano | findstr 端口` / Linux `lsof -i:端口`
- **处理**：修改`server.php`端口配置，同步修改前端页面内置地址。

### 3. 网页播放器无法拉流

1. 确认服务正常运行、防火墙放行端口
2. 核对页面内播放地址和推流 `app/stream` 名称一致
3. 低并发场景直接使用源站地址（`http://127.0.0.1/xxx.html`）
4. 高并发场景通过静态文件网关访问播放页面

### 4. 录制任务如何独立配置？

修改 `server.php` 中的三个常量：
```php
define('FLV_TO_RECORD', true);   // 是否录制FLV原始文件
define('FLV_TO_MP4', true);      // 是否生成fMP4切片并合并为MP4
define('FLV_TO_HLS', true);      // 是否生成HLS(TS)切片
```
每个任务可独立开启/关闭，互不影响。

### 5. MP4 文件什么时候生成？

- **实时性**：fMP4 切片在推流过程中实时生成（供 MSE 播放）
- **合并时机**：完整 MP4 文件在**直播结束后自动合并**生成
- 如需直播过程中就有 MP4，建议使用 FLV 格式或 HLS 格式

### 6. fMP4 混合切片和分离切片有什么区别？

| 特性         | 混合切片（output_merge）                 | 分离切片（output_separate）               |
| ------------ | ---------------------------------------- | ----------------------------------------- |
| 文件结构     | 单文件包含音视频                         | 音频、视频分片独立                        |
| 播放方式     | 单 SourceBuffer                          | 双 SourceBuffer 同步                      |
| 适用场景     | 简单实现，兼容性好                       | 精细化控制，可独立处理音视频              |
| 播放页面     | `play_merge.html`（自动适配两种格式）    | `play_merge.html`（自动适配两种格式）     |

### 7. 网关播放卡顿、频繁掉线

1. 检查上游源站网络稳定性
2. 建议网关层级≤3级，层级越多延迟越高
3. 开启网关Debug日志定位异常：`$gateway->debug = true;`
4. 高并发场景可增加网关节点横向扩容

### 8. 什么时候需要部署网关？

| 并发场景                 | 部署方案                                      |
| ------------------------ | --------------------------------------------- |
| **低并发**（< 1000）     | 仅源站即可，源站内置 HTTP 服务直接对外        |
| **高并发**（> 1000）     | 源站 + FLV网关集群 + 静态文件网关集群         |
| **百万级并发**           | 多级 FLV 网关 + 多实例静态文件网关，横向扩容  |

### 9. FLV网关和静态文件网关的区别？

| 网关类型         | 用途                       | 处理的资源类型                              | 并发能力               |
| ---------------- | -------------------------- | ------------------------------------------- | ---------------------- |
| **FLV直播网关**  | 直播流分发                  | HTTP-FLV 实时流                             | 横向扩容支撑百万级     |
| **静态文件网关** | 静态资源统一托管            | HLS/fMP4/MP4/FLV静态文件 + Web播放页面      | 横向扩容支撑百万级     |
